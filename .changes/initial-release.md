Initial release: a structured logging library for Luau that runs on both Lute and Roblox. Dot-style leveled loggers (`trace`/`debug`/`info`/`warn`/`err`) with `LOG_LEVEL` resolution, structured `LogRecord`s, child loggers with attached fields, dev/prod batching, and sinks for the console, files (Lute), custom callbacks, and buffered transports.
